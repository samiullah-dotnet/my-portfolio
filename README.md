# Sami Ullah — .NET Developer Portfolio

A responsive, dark-themed portfolio starter for an aspiring C#/.NET backend developer.

## Run locally
1. Extract this folder if you downloaded the ZIP.
2. Open `index.html` in a browser, or open the folder in VS Code and use the Live Server extension.

## Personalize before publishing
- In `script.js`, replace `your.email@example.com` with your real professional email.
- In `index.html`, update GitHub and LinkedIn links to your real profiles.
- Update project descriptions so they only claim features you have actually completed.
- Add repository links to the project cards once the code is uploaded to GitHub.
- Only list technologies and skills you can explain in an interview.

The contact form opens the visitor's email application; it does not send or store messages on a server.
